# Native-interface target protocol

`data/interfaces/native_interface_v1.jsonl` is an immutable 58-row audit of
the pinned Hugging Face tokenizer revisions. It was generated by
`persona-audit audit-native-interfaces`: `chat_template.jinja` takes precedence
over an embedded `tokenizer_config.json` template, matching Transformers.

There are 40 `raw_completion` base checkpoints with no declared chat template,
and 18 `native_chat_template` post-trained/wild checkpoints. Native prompts use
exactly one user message containing the frozen target string, set
`add_generation_prompt=True`, and add no researcher-authored system message.
Some released templates themselves insert a default system turn; that is part
of the published model interface and is retained rather than silently removed.

The runner deliberately regenerates only the 18 `native_chat_template` models.
The 40 base models' native interface is raw completion, so their completed
records in `runs/targets/v1` are already the exact native-interface data; a
second generation would be duplicated compute. This is a companion
deployment-interface panel, not a replacement for `runs/targets/v1`, which is
the controlled raw-string panel shared by all 58 weight checkpoints. Keep the
output namespaces and metadata separate.
